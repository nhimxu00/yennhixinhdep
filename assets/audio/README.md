# Site music

`a-thousand-years.mp3` is the **A Thousand Years (Piano/Cello Cover)** recording supplied by the site owner for this personal website. The source file was copied without changing its audio.

The timeline and letter pages request audible autoplay, loop the recording, and preserve the playback position between pages. When a browser blocks autoplay, opening the letter or tapping the music button retries playback during a user gesture. Playback indicators reflect the audio element's actual state. Visitors can pause the music.

`hbd.mp3` remains the existing birthday soundtrack.
